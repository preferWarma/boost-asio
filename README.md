# 基于Boost::Asio的网络编程
基于 Boost::Asio 设计并实现高性能 TCP 服务器，支持高并发客户端连接，采用异步网络编程与分层架构，结合线程池和 IOC 池优化资源管理，集成异步日志系统、配置管理模块等，项目代码具有高可维护性和高扩展性。

- **异步网络框架**：基于 Boost::Asio 实现异步通信，使用 C++11 智能指针实现伪闭包机制，解决 Session 对象的生命周期管理问题，有效避免资源泄漏和悬空指针等问题
- **C++20 协程支持**：引入 C++20 协程技术，为客户端会话处理提供协程实现方案，简化异步编程模型，有效提升服务器在处理大量并发任务时的资源利用率。
- **异步日志系统**：采用独立的线程和队列机制，支持分级输出，将服务器运行过程中的各类日志信息异步写入文件，避免了日志操作对主线程的阻塞，有效提升服务器的整体性能。
- **高并发支持**：为客户端连接提供线程池和 IOC 池双方案，动态分配 I/O 与计算资源，优化了网络操作的并发性能，支持 5000+ 并发连接和会话处理
- **分层架构设计**：基于单例模式设计逻辑系统实现网络层与逻辑层的分离，解耦请求处理与业务逻辑，支持动态回调注册。
